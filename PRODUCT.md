# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Standalone HTML/CSS/JavaScript interactive prototype, confirmed by the user. CTFd integration is a later deliverable.

## Product Purpose

Explore a CTFd theme that presents challenges as messages in a retro email client.

## Capabilities and Constraints

- Categories are inbox folders.
- Challenge titles are email subjects.
- Email bodies show challenge descriptions, files, hints, and flag submission.
- Prototype uses sample challenges.
- No bookmarking or “Flag for later” feature.
- Inbox columns can be resized and reordered; column preferences are not saved.
- Prototype senders are fictional; the production “From” mapping is undecided.
- Solved challenges are read; unsolved challenges are unread. Opening a message does not mark it read.
- Target the latest stable CTFd release, verified as 3.8.7 on 2026-09-22.
- Individual mode: rankings and profiles are per user; team flows are outside the current design scope.
- Deployment is undecided.

## Brand Commitments

Retro / Windows XP email-client aesthetic.
Application name: Challenge Express. Window and browser titles include the current folder alongside the application name.
Use ordinary hyphens instead of em dashes in UI text and source code.
